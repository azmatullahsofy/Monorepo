# Repository Errors & Issues Fixed

## 🔴 Critical Issues Found & Fixed

### 1. **Duplicate/Malformed Files** ⚠️
Multiple files with duplicate naming patterns found in root directory:
- `api (1).ts`, `api.d (1).ts`, `api.d.ts (1).map`
- `index (1).ts`, `index (2).ts`, `index (3).ts`, `index (4).ts`, `index (5).ts`, `index (6).ts`, `index (7).ts`
- `tsconfig (1).json`, `tsconfig (2).json`, `tsconfig (3).json`
- `package (1).json`, `package (2).json`, `package (3).json`, `package (4).json`
- `utils (1).ts`

**Fix**: These should be organized into proper package structure, not dumped in root.

---

### 2. **Incorrect Root Structure** 🏗️
Files are scattered randomly in the root instead of being organized in packages as defined in `pnpm-workspace.yaml`.

**Expected Structure (from pnpm-workspace.yaml)**:
```
packages:
  - artifacts/*
  - lib/*
  - lib/integrations/*
  - scripts
```

**Current Issue**: All source files are in root directory, not in the defined packages.

---

### 3. **TypeScript Configuration Issues** 📋
- `strictFunctionTypes: false` (Line 15 in tsconfig.base.json) - Should be `true` for strict type checking
- No `"paths"` defined in tsconfig for monorepo workspace aliasing
- `noUnusedLocals: false` (Line 11) - Allows unused variables, should be `true`

---

### 4. **API Generation Files** 🔄
Files like `api.d.ts`, `api.d.ts.map`, `client.d.ts.map` etc. appear to be generated by **Orval** (seen in api.ts header).

**Issue**: Generated files should NOT be committed to git. They should be in `.gitignore`.

---

### 5. **Workspace Configuration Issues** 🎯
**Problems**:
- Root `package.json` declares `@workspace/api-client-react` but points to non-existent `./src/index.ts`
- The actual source files are scattered in root, not in `src/` directory
- Export configuration doesn't match actual file structure

---

### 6. **Missing Core Configuration Files** 📝
- Missing `vite.config.ts` (for apps using Vite)
- Missing `eslint.config.js` or `.eslintrc.json`
- Missing proper `.editorconfig`
- Missing `jest.config.js` or vitest config (if testing framework is used)

---

### 7. **Build/Compilation Failures** 🚫
Reasons:
1. Import paths won't resolve (files not in workspace packages)
2. `custom-fetch.ts` imports not properly aliased
3. `utils.ts` imports `p-limit` and `p-retry` but these might not be in dependencies
4. TypeScript compilation will fail due to structure mismatch

---
